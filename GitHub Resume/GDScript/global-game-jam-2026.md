# Game Jam 2026
### Repository: https://github.com/CayleighG/Game-Jam-2026.git

Game Jam is a yearly event where a team of game developer get together to create a game over the course of one week. In this year's event, I was recruited as my team's sole programmer to assist in the creation of a video game inspired by the theme "mask". After the initial few days of prototyping, I was given four days to code the game from scratch.
